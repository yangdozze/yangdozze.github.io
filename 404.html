WaveDrop Studio

From finished beat to published video.

WaveDrop Studio is a Windows desktop application for independent beatmakers. It combines a beat audio file and cover image into a YouTube-ready video, helps prepare titles, descriptions and tags, detects BPM and key from filenames, supports release planning, and uploads to the user's own YouTube channel only after explicit review and approval.

Application purpose

What WaveDrop Studio does.

WaveDrop Studio is a Windows desktop publishing tool for music creators. Users select their own beat and cover art, generate a video without intentionally changing the source audio quality, prepare reusable release metadata, connect their own YouTube channel through Google OAuth, and start an upload only by clicking the publishing action themselves.

Google & YouTube

A clear, user-controlled connection.

WaveDrop Studio uses Google OAuth in the user's browser. The app requests only the YouTube permissions needed to identify the selected channel and upload a video the user has prepared.

  1. 1ConnectGoogle opens the authorization screen in the default browser.
  2. 2ReviewThe user sees and approves the exact requested permissions.
  3. 3PublishAn upload starts only when the user clicks the publishing action.
  4. 4DisconnectAccess can be revoked at any time from the Google Account.

WaveDrop Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
