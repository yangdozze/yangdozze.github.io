WaveDrop Studio

Application name: WaveDrop Studio. This is the official public homepage for the WaveDrop Studio desktop application.

Purpose of WaveDrop Studio: WaveDrop Studio is a Windows desktop application for independent beatmakers. It turns a user-selected beat audio file and cover image into a YouTube-ready video, helps the user prepare release metadata and schedules, and lets the user upload that video to the user's own YouTube channel only after the user reviews the details and explicitly starts the upload.

What WaveDrop Studio does

  • Combines user-provided audio and cover artwork into a video.
  • Helps prepare titles, descriptions, tags, BPM, musical key and release metadata.
  • Supports planning and scheduling releases.
  • Connects Google OAuth only when the user chooses to enable YouTube publishing.
  • Uploads only after an explicit user publishing action.

Why WaveDrop Studio requests Google access

WaveDrop Studio requests Google and YouTube access only so the user can publish a prepared video to the user's own YouTube channel from the desktop application. The app does not request the user's Google password and does not upload content automatically.

OAuth authorization tokens are stored locally on the user's device. Users can revoke access from their Google Account at any time.

Google OAuth scope used by WaveDrop Studio

https://www.googleapis.com/auth/youtube.upload
Purpose: used only when the user explicitly publishes a prepared video from WaveDrop Studio to the user's own YouTube channel. This permission is necessary because uploading a YouTube video requires the YouTube upload scope. WaveDrop Studio does not request broader YouTube account-read or account-management scopes.

User control and data handling

Every upload is user initiated. The user selects the files, reviews the video metadata and publishing settings, and then starts the upload. WaveDrop Studio does not sell Google user data, use it for advertising, or share it with unrelated third parties. Application settings and Google authorization tokens are stored locally on the user's Windows computer.

Optional tag research uses public YouTube video metadata and does not request additional OAuth access to private Google or YouTube account data.

For complete details about access, use, storage, sharing, retention and deletion of Google user data, read the WaveDrop Studio Privacy Policy.
