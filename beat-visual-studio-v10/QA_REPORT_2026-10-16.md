## Verified audio smoke test
- Browser test: https://wavedropstudio.ru/beat-visual-studio-v10/qa-audio.html
- Generated a 2-second, 44.1 kHz, mono PCM synthetic rhythm inside the browser.
- Called the actual native engine on the same PCM at 0.25, 0.55, 1.05 seconds. Read exported canvas pixel hashes. Different hashes verify changing frames over time but **do not alone prove spectral sensitivity** against silence.
- Measured render duration in the QA browser (not guaranteed FPS on mobile devices):

| METHOD family | first frame ms | following frame ms | unique frame hashes | exceptions |
|---|---:|---:|---:|---|
| Retro | 39 | 19 / 11 | 3 | none |
| Contour | 717 | 364 / 367 | 3 | none |
| Dust | 869 | 443 / 435 | 3 | none |
| Spatial | 3149 | 2380 / 2369 | 3 | none |
| Volume | 6235 | 3889 / 3952 | 3 | none |

## Interpretation
- Retro is responsive enough for a first real-time preview in the tested browser. Other engines, especially Spatial and Volume, are expensive and currently **do not meet the 30/60 FPS live-preview target** in this environment.
- A static look-selection/browser workflow was also exercised, but that test appeared to reference an older v10 Method Lab page and is not sufficient evidence about the present v10 Native Library's exact DOM or its final mobile layout.
- Long-form 1080p export, audio sync on user MP3s, real iOS Safari performance, source-versus-BVS video comparisons, and all remaining original METHOD families must still be tested.
