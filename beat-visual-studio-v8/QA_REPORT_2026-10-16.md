# Beat Visual Studio v8 — Original METHOD Caustic Integration QA
Date: 2026-10-16

## Origin / license
- Original project: https://method.hiveglobal.org/app/#/caustic
- METHOD / HiveGlobal remain credited in the UI. Authorization to reuse the code was relayed by the Beat Visual Studio owner. No claim of independent rights transfer.
- The CAUSTIC core in `caustic-core.js` matches the original inline METHOD CAUSTIC engine body, checked by string equality.
- `method-caustic-adapter.js` is adapted from METHOD's original CausticAdapter; preserves original Look names and defaults.
- `method-tracker-hud.js` is a host-only high-resolution visualization of *authentic* tracked coordinates — it does not generate targets.

## Fixed
- v7 rendered on iPhone using a 176px raster; original METHOD uses 540×960.
- v8 uses native 540×960 raster for Caustic, Displaced, Thermal, including exported frames.
- Default Displace=1.00, Speed=.97, Tracker=.65 for Displaced and Thermal; Thermal tracker is not forced off.
- The METHOD tracker algorithm now updates its positions without painting tiny captions onto the 540px raster. Beat Visual Studio draws those same IDs, coordinates, five palettes and connector lines on the output-size canvas for legibility.
- Previous v5 and v7 remain unchanged; STRIP/NIGHT and the removal of Audio-to-MIDI were preserved.

## Remaining limitations
- Not a direct pixel-for-pixel comparison with METHOD running the exact same user WAV. Original site has no built-in demo sound for that check.
- Full-screen playback and 1080p 60 FPS export need further tests on physical iPhone/Safari with representative real songs.
- Running the original METHOD 540×960 CPU raster may be costly for low-powered phones. Do not assume sustained 60fps preview.
