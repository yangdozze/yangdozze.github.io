WaveDrop Studio

WaveDrop Studio turns a finished beat and cover artwork into a YouTube-ready video, helps the user prepare release metadata and schedules, and can publish that video to the user's own YouTube channel.

The application is designed for independent music producers who want one desktop workflow for video preparation, metadata, release planning and YouTube publishing. A YouTube upload never starts automatically: the user reviews the content and metadata and explicitly starts the upload.

Application purpose

What WaveDrop Studio does

WaveDrop Studio is a local Windows publishing tool for beatmakers. Users provide their own audio and artwork. The app creates the video locally, lets the user prepare and review publishing information, connects the user's own YouTube channel through Google OAuth, and uploads only after an explicit user action.

01

Create a video

Combine a user-selected beat audio file and cover image into a YouTube-ready video while keeping the source audio workflow under the user's control.

02

Prepare metadata

Create and reuse titles, descriptions and tags, detect BPM and musical key from filenames, and organize release information before publishing.

03

Plan releases

Keep release schedules and publishing preferences in the desktop application so the user can prepare uploads before they are sent.

04

Connect a channel

Use Google OAuth to connect the user's own YouTube channel and display the connected channel so the user can verify the destination.

05

Review before upload

The user reviews the selected video, title, description, tags, visibility and other publishing settings before the app sends anything to YouTube.

06

Publish by choice

The YouTube upload begins only after the user clicks the upload/publish action. WaveDrop Studio does not silently or automatically publish videos.

Google & YouTube data access

Why WaveDrop Studio requests Google user data

Google access is requested only for visible YouTube features inside WaveDrop Studio. The user chooses to connect a Google account, sees Google's OAuth consent screen, and can revoke access at any time from their Google Account.

https://www.googleapis.com/auth/youtube.readonly

Identify the connected channel

This permission is used to read basic information about the authenticated user's YouTube channel, such as its channel ID and display title, so WaveDrop Studio can show the user which channel is connected before publishing.

https://www.googleapis.com/auth/youtube.upload

Upload the user's video

This permission is used to upload a video and the metadata approved by the user to that user's own YouTube channel after the user explicitly starts publishing. A more limited permission does not provide YouTube video upload functionality.

No automatic publishing. WaveDrop Studio does not upload a video in the background or without a user-initiated publish action.

Local token storage. Google OAuth authorization tokens are stored on the user's device for the desktop connection and are not sent to a WaveDrop Studio backend server.

No advertising or sale of Google user data. Google user data is not sold, used for advertising, credit decisions, surveillance, or training generalized AI/ML models.

Minimum access. WaveDrop Studio requests the YouTube permissions used by the visible channel-identification and user-initiated upload features.

Limited Use: WaveDrop Studio's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
