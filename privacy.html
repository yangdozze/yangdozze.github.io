Privacy Policy

Effective August 7, 2026

This Privacy Policy applies specifically to WaveDrop Studio, a Windows desktop application for beatmakers that creates YouTube-ready videos, prepares release metadata and can upload user-approved videos to the user's own YouTube channel.

Google API Limited Use disclosure

WaveDrop Studio's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

1. Information WaveDrop Studio handles

User-provided local files and metadata

WaveDrop Studio processes files and information the user chooses to provide, including audio files, cover images, rendered videos, titles, descriptions, tags, BPM, musical key, release schedules and publishing preferences.

Google and YouTube user data

When the user chooses to connect a YouTube channel through Google OAuth, WaveDrop Studio may handle:

  • basic information about the authenticated user's YouTube channel, such as channel ID, display title and related channel information returned by the YouTube Data API;
  • Google OAuth authorization and refresh tokens issued for the permissions approved by the user; and
  • video upload results and identifiers returned by YouTube for uploads explicitly started by the user.

WaveDrop Studio does not request or receive the user's Google password.

2. Google OAuth permissions and why they are requested

WaveDrop Studio requests only the permissions needed by its visible YouTube features:

  • https://www.googleapis.com/auth/youtube.readonly — used to identify and display the authenticated user's connected YouTube channel so the user can confirm the publishing destination.
  • https://www.googleapis.com/auth/youtube.upload — used to upload a user-selected video and user-approved metadata to the user's own YouTube channel after the user explicitly starts publishing.

WaveDrop Studio does not use these permissions to silently publish videos. The upload permission is required because a more limited permission does not provide YouTube video upload functionality.

3. How Google user data is used

Google user data is used only to provide the visible features requested by the user:

  • show which YouTube channel is connected;
  • maintain the user's authorized YouTube connection on the local device;
  • upload a video and its approved metadata after an explicit user publishing action; and
  • display upload progress, success information or errors returned by YouTube.

Google user data is not used for advertising, retargeting, personalized ads, credit decisions, lending decisions, surveillance, or to train or improve generalized artificial intelligence or machine-learning models.

4. Storage and protection

WaveDrop Studio is a desktop application and does not operate a WaveDrop Studio backend server that collects the user's Google OAuth tokens. OAuth tokens, application settings and local project information are stored on the user's own device.

The application limits Google user data handling to the local application and the direct requests necessary to communicate with Google's and YouTube's APIs. Users should protect their operating-system account and device because locally stored application data inherits the security of that device and user account.

5. Sharing, transfer and disclosure

WaveDrop Studio does not sell Google user data and does not transfer Google user data to advertisers, data brokers or unrelated third parties.

Data is transmitted to Google/YouTube only as necessary to provide the OAuth-authorized YouTube functionality requested by the user, such as uploading the selected video and approved metadata. Data may otherwise be disclosed only when required by applicable law or when necessary for security purposes consistent with Google's policies.

6. Retention and deletion

Locally stored settings and authorization data remain on the user's device until the user removes them, disconnects the YouTube account, clears WaveDrop Studio application data, or uninstalls the application.

The user can revoke WaveDrop Studio's Google access at any time through the Google Account third-party connections/security settings. After access is revoked, the stored authorization can no longer be used to access YouTube. The user may also delete local WaveDrop Studio data from their device.

7. User control and consent

Connecting YouTube is optional. The Google OAuth authorization flow begins only after the user chooses to connect a Google account. Publishing begins only after the user reviews the relevant content and settings and explicitly starts the upload.

8. Changes to this policy

If WaveDrop Studio changes how it accesses, uses, stores or shares Google user data, this policy will be updated before the new use is introduced. Where required, users will be notified or asked to provide updated consent.
